# OSSP Concept Mapping

| Project component | Linux/OS concept |
|---|---|
| Process manager | fork(), execvp(), waitpid() |
| Error handling | return values, errno, error descriptions |
| Tracer | strace, system-call observation |
| Process monitor | /proc, PID/PPID and process state |
| Abnormal termination | signals and wait status |
| Logging | Linux file I/O through standard C file streams |
| Controlled tests | user-space processes and system-call failures |
